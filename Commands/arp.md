# ARP

- arp -a
  - on windows, mac, linux

- show mac address-table 
  - on Cisco switch
  - show mac address table on cisco switch with the following fields
    - VLAN, MAC Address, Type, Ports

- clear mac address-table dynamic
  - remove all dynamically created rows in the mac address table

- clear mac address-table dynamic address <mac-address>
  - clear a specific mac address row with the specified mac-address
  
- clear mac address-table dynamic interface <interface-id>
  - clear a specific mac address row with the specified interface
